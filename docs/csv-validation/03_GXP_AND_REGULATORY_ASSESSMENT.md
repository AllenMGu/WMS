# CSV-03 GxP 影响与法规适用性评估

## 1. GxP 判定

结论：本系统直接创建、修改、审批、检索和保留药品经营质量活动记录，并控制批次放行、质量锁定、库存、退回、召回和运输，因此属于 GxP 关键计算机化系统，必须采用基于风险的生命周期验证。

该结论不等于系统已满足全部法规。企业质量部门必须结合许可证范围、冷链、特殊管理药品、疫苗、委托储运、地区监管要求和内部 SOP 确认最终适用性。

## 2. 法规与指南基线

| 来源 | 适用主题 | 本文件体系 |
|---|---|---|
| 《药品经营质量管理规范》及现行附录 | 组织、质量体系、采购、收货、验收、储存、销售、运输、退货、召回、计算机系统 | URS、FS/DS、IQ/OQ/PQ、SOP |
| NMPA 计算机系统相关附录 | 权限、数据、修改、备份、记录可追溯 | CSV-10、CSV-11、CSV-12 |
| NMPA 验证管理相关附录 | 验证计划、方案、报告、偏差和再验证 | CSV-01、CSV-06~09、CSV-14、CSV-16 |
| NMPA 温湿度监测相关附录 | 设备、校准、连续监测、告警、数据 | CSV-05、CSV-07、CSV-13 |

若企业同时声明适用 21 CFR Part 11、EU GMP Annex 11、GAMP 5 或集团全球标准，应由质量部门另行批准适用性矩阵；本版不自动作出境外法规合规声明。

## 3. 电子记录和电子签名范围

| 记录/动作 | GxP 关键性 | 最低控制 |
|---|---|---|
| 质量审批、驳回、放行、锁定解除 | 关键 | 独立岗位、身份再确认、签名含义、对象和请求绑定 |
| 采购/销售审批 | 关键 | 职责分离、批准依据、状态机、审计 |
| 收货、抽样、验收、销退检验 | 关键 | 人员/时间/批次/数量/结论、不可静默修改 |
| 不合格处置、退供、销毁见证 | 关键 | 多角色分离、证据、库存原子变化 |
| 召回、进展和关闭 | 关键 | 目标完整、时限、回收数量、独立关闭 |
| 用户/岗位/仓库授权 | 关键 | 独立授权和复核、有效期、审计、停用回收 |
| 配置、秘密轮换、备份恢复 | 关键 | 批准、实施、验证分离及证据 |
| 查询、导出、打印 | 支持性/可能关键 | 过滤条件、时间、模板/份号、内容完整 |

## 4. ALCOA+ 控制映射

| 原则 | 系统控制 | 验证方法 |
|---|---|---|
| 可归属性 Attributable | 唯一账号、岗位授权、人员快照、来源 IP | 账号共享负向、停用、岗位过期、自批测试 |
| 清晰 Legible | 标准化 API/UI、只读检索、导出/打印 | 浏览器、导出、归档可读性测试 |
| 同步 Contemporaneous | 服务器 UTC 时间、NTP、操作时间自动记录 | NTP 偏差、时区和时间戳顺序测试 |
| 原始 Original | 原始业务记录、请求摘要、读数原始载荷摘要 | 原始证据与派生报表核对 |
| 准确 Accurate | 数据校验、外键、唯一约束、事务和复核 | 边界、并发、失败回滚、抽样核对 |
| 完整 Complete | before/after 审计、取消不删历史、召回目标 | 删除/修改负向、历史查询、链验证 |
| 一致 Consistent | 状态机、时间序列、批次账务和 revision | 非法状态转换、顺序与库存一致性 |
| 持久 Enduring | PostgreSQL、备份、异地副本、受控归档 | 备份校验、隔离恢复、保留测试 |
| 可获得 Available | 授权检索、审计查询、恢复和导出 | 权限查询、恢复后抽查、导出校验 |

## 5. 数据完整性关键风险

- 共用账号、LDAP 身份映射错误或岗位超期导致记录不可归属；
- 前端隐藏按钮但后端未阻断越权；
- 签名令牌过期、重放、跨对象使用或请求正文改变后仍可执行；
- 审计事件删除、覆盖、链断裂或时间顺序异常；
- 取消/驳回通过物理删除明细造成历史缺失；
- 并发分配/退供/盘点导致超卖、重复扣减或半成品；
- 历史迁移数量正确但字段映射、可读性、权限或哈希不正确；
- 备份生成但无法恢复，或备份与生产位于同一故障域；
- 暂缓接口被误启用并被当作已验证能力。

上述风险必须在风险评估、RTM 和实际测试证据中闭环。

## 6. 记录保留与隐私

记录保留期由企业法规和质量制度批准，不在代码或本模板中擅自设定。公开 GitHub 仓库只能保存模板、脱敏测试材料和非敏感证据摘要；正式数据库备份、个人信息、账号、客户/供应商资料、证书、密钥和详细日志必须存放在批准的受控介质中。

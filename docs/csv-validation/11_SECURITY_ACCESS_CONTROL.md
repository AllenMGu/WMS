# CSV-11 安全、账号、权限与职责分离

## 1. 身份控制

- 每人唯一账号；禁止共享质量、管理员和服务账号进行人工操作。
- 本地或 LDAP 身份必须映射到唯一应用用户；首次登录不得自动获得仓库或 GSP 岗位。
- 登录失败按账号/IP 持久限流；停用、离职、岗位撤销和仓库撤销应立即生效。
- 密码策略由身份源批准；本系统不得在日志或审计中保存密码。
- 紧急账号的启用、使用、复核和停用必须有独立审批和事后审查。

## 2. 系统岗位与冲突

岗位权限详见 `records/role_permission_matrix.csv`。代码在 `app/gsp/access_control.py` 定义岗位白名单及冲突。最低验证包括：

| 岗位 A | 不得兼任/冲突岗位摘要 |
|---|---|
| `AUDITOR` | 除审计员外全部 GSP 岗位 |
| `PROCUREMENT` | 验收、质量经理/复核、收货 |
| `SALES` | 发运、出库复核、质量经理/复核 |
| `OUTBOUND_REVIEWER` | 拣货、销售、仓库保管 |
| `ENVIRONMENT_MONITOR` | 审计员、质量经理/复核 |
| `STOCKTAKE` / `WAREHOUSE_MANAGER` | 质量经理/复核 |
| `SYSTEM_ADMIN` | 审计员、质量经理/复核 |
| `TRANSPORT_COORDINATOR` | 审计员、质量经理/复核 |

此外必须验证记录级职责分离，例如创建人与批准人、收货人与验收人、拣货人与出库复核人、登记人与不合格处置批准人、销毁执行人与见证人、签收人与关闭人、备份执行人与复核人。

## 3. 仓库范围

为每个业务岗位配置一个允许仓库和一个禁止仓库。分别验证列表、详情、创建、状态操作和导出；只在前端隐藏不算通过。撤销仓库映射、切换当前仓库、停用用户后重新测试现有会话。

## 4. LDAP 配置

| 模式 | 生产要求 |
|---|---|
| LDAPS | URI/SSL 配置一致，验证服务器证书和 CA |
| StartTLS | 389 建连后强制升级并验证证书 |
| 普通 LDAP 389 | 仅在书面风险接受、网络隔离和补偿控制下显式启用 |

验证 `LDAP_USE_SSL` 与 `LDAP_START_TLS` 不能同时启用；配置管理员 DN 时必须提供凭据版本引用。证据仅显示传输模式和版本引用，不显示绑定密码。

## 5. 定期访问复核

企业应规定复核频率。复核清单至少包含：用户启用状态、部门/岗位、GSP 岗位、仓库、批准依据、授权人、最近复核、下次复核、失效期、冲突和最近登录。复核人与被复核用户不同；过期授权应被系统阻断而不是仅产生提醒。

## 6. 安全测试接受标准

所有越权、自批、岗位冲突、仓库越界、停用、过期和错误认证均被后端阻断且不改变数据；授权/复核/撤销有完整审计；公开仓库和日志无秘密或个人敏感数据。

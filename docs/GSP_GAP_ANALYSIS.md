# GSP 差距矩阵

基线日期：2026-08-20。第一版按药品批发企业，以及药品生产企业销售、储存和运输环节的共同要求设计；
实际经营范围（冷链、特殊管理药品、委托储运、疫苗等）确认后还需细化。

## 功能与控制差距

| 优先级 | 能力 | 现状 | 本次变化 | 下一步验收标准 |
|---|---|---|---|---|
| P0 | 唯一账号与最小权限 | 仅管理员/操作员；LDAP 首登获全部仓库 | 新增 GSP 岗位授权，取消自动全仓权限 | 批准权限矩阵；岗位互斥；定期复核与离职回收 |
| P0 | 系统配置与秘密 | 数据库/JWT/LDAP 写在源码 | 全部改为环境变量；生产拒绝弱 JWT 密钥 | 使用秘密管理；密钥轮换与双人审批 |
| P0 | 供货方/购货方资质 | 只有自由文本名称 | 新增合作方、许可证范围/效期、审批/暂停 | 补资质附件、销售/采购人员授权、效期自动锁定 |
| P0 | 经营品种质量主数据 | 只有条码、名称、规格、价格 | 新增批准文号、剂型、持有人、储存条件、追溯要求和审批 | 与 NMPA/企业批准档案核对；变更重新审批 |
| P0 | 批号与有效期 | 通用库存无批号 | 新增药品批次、批号库存、剩余有效期、FEFO 预留、发运扣减及销后退货合格回库；已建 GSP 质量档案的品种被禁止使用旧版无批号接口 | 补购进退出与盘点差异后，所有药品库存操作统一使用批号库存 |
| P0 | 收货与验收分离 | 旧入库单提交即增加库存 | 新增采购→质量审批→按单收货→独立验收→批次库存闭环及岗位互斥；GSP 品种旧通道已阻断 | 补抽样方案、拒收后续处置和受控打印记录 |
| P0 | 质量可疑药品锁定 | 无 | 新增质量锁定/解除，批号库存同步 HOLD | 所有销售、拣货、出库接口统一调用阻断规则 |
| P0 | 审计追踪 | 普通记录可改、可删，无前后值 | 新增变更原因和哈希链审计事件 | 覆盖用户、权限、配置及所有受控业务；定期校验哈希链 |
| P0 | 每日备份与恢复 | 无应用化证据 | 增加备份脚本 | 调度、异地/离线保存、告警、季度恢复演练和记录 |
| P1 | 出库复核 | 旧出库单提交直接扣库存 | 新增购货方/品种资质审批、FEFO、库存预留、拣货、独立复核和发运扣减 | 补扫码逐箱复核、包装记录、随货同行单和电子签名策略 |
| P1 | 近效期控制 | 无 | 合规概览统计 90 天近效期 | 可配置阈值、自动养护/停销、报警闭环 |
| P1 | 温湿度监测 | 无 | 批次可关联冷链温度记录并做范围判断 | 对接实时监控、超限报警、偏差处理和不可篡改记录 |
| P1 | 退货/召回/不合格品 | 仅入库退库 | 新增销后退回原发运关联、待检隔离、独立质量检验、合格回库/拒收处置方向；新增批次召回、库存锁定、购货方通知、回收数量核对和独立关闭 | 补购进退出、不合格品审批销毁、召回时限/演练与监管报送 |
| P1 | 运输与在途 | 无 | 新增承运商、车辆、司机、运输方式和冷链温度记录引用；发运写入出站箱 | 补承运商资质、路线时限、实时温度、交接、在途异常和签收追踪 |
| P1 | 养护 | 无 | 未完成 | 自动生成养护计划、异常锁定、近效期与重点品种策略 |
| P1 | 药品追溯 | 无 | 批次可强制追溯码 | 明确追溯平台/码制，完成采集、核销、上传、失败补偿 |
| P1 | 九州通对接 | 无 | 建独立出站箱与幂等模型 | 按正式接口规范开发适配器并完成联调、对账、重放测试 |
| P2 | CSV/验证 | 无 | 增加验证计划骨架、16 项自动化测试、SQLite/PostgreSQL 迁移门禁和固定 SHA 的 GitHub Actions | 完成 VP/URS/RA/FS/DS/RTM/IQ/OQ/PQ/报告/放行；CI 结果不能替代批准的验证证据 |

## 当前投用结论

当前版本可以作为 **GSP 开发基础和原型验证环境**，不能直接作为受控生产系统上线。P0 项中，
“购进退出/不合格品处置/养护闭环”“受控数据完整审计覆盖”“每日备份与恢复证据”“完整验证”完成前，
旧 `/api/inbound-orders`、`/api/outbound-orders`、`/api/inventory/scan` 不应承担药品正式账务。
